# PromptVault — 500+ Free AI Prompts

> Copy-paste AI prompts for your profession. Always free, no sign-up.

**PromptVault** is a curated library of **500+ tested AI prompts** for ChatGPT, Claude & Gemini, organized by profession — teachers, nurses, HR, writers, developers, and more.

## ✨ Features

- 🧠 **500+ profession-specific prompts** — tested and organized by role
- 📂 **Filter by category** — teachers, nurses, HR, writers, marketing, legal
- ⚡ **One-click copy** — paste straight into ChatGPT, Claude, or Gemini
- 🎯 **Prompt engineering tips** — get better answers from any AI model
- 📱 **Fully responsive** — works beautifully on mobile and desktop
- 🆓 **100% free** — no sign-up, no paywall, ever

## 🛠️ Built With

- Pure HTML5 + CSS3 + vanilla JavaScript
- Zero frameworks, zero dependencies
- Mobile-first responsive design
